# SANGYAN Suraksha

A hackathon-ready MVP for investor protection, scam resilience,
financial misinformation awareness and safer decision-making.

## Features

- Explainable financial scam-risk analysis
- Red-flag detection
- Risk score from 0 to 100
- Hindi and English summaries
- Voice input using browser speech recognition
- URL extraction
- Local SQLite history
- Official resource links
- No buy/sell/hold recommendations
